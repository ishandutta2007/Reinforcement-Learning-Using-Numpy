
# NumPy-Only Reinforcement Learning Demo

A minimal, self-contained Q-learning example that trains a 4×4 grid-world agent **without any library except NumPy**.

---

## What it does
- Solves a frozen-lake style task (start ➜ goal, avoid traps).  
- Learns the optimal policy in <1 s on a laptop.  
- Shows every step so you can paste the code into a notebook and hack away.

---
